# Privacy and network use

Absolute Memory sends no telemetry. In Lite, it stores the library, account data and original files in the instance volume by default.

| Connection                                               | When it occurs                                                                                                                                                                                                                                                             |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Source website, CDN, RSS host, or a redirect destination | The instance fetches a link you save or retry. It resolves address records and checks destinations before connecting. Media extraction may contact the source, caption and audio CDNs.                                                                                     |
| Related source domains                                   | YouTube retrieval uses the site's media endpoints. Podcast lookup can use Apple's public iTunes search and the show's public feed. arXiv saves can query export.arxiv.org for metadata. Reddit saves can query public post endpoints and, with credentials, its OAuth API. |
| Remote images in the browser                             | When the operator sets `ALLOW_REMOTE_IMAGES=true`, viewing a saved item or library card can load images from sites referenced in the save. The browser blocks these requests by default. Uploaded images and locally rendered previews remain available.                   |
| YouTube embed in the browser                             | Playback loads the YouTube privacy-enhanced iframe after you press Play. Opening any original link follows the normal browser behavior for that site.                                                                                                                      |
| Chat model endpoint                                      | Sends the requested prompt, relevant saved passages, conversation context, or content being summarized. Careful PDF reading or image analysis can send the original file.                                                                                                  |
| Embeddings endpoint                                      | Sends text chunks and search queries when embeddings are enabled.                                                                                                                                                                                                          |
| Transcription endpoint                                   | Sends normalized audio when requested media does not provide a usable transcript, or when you upload local media.                                                                                                                                                          |
| PostgreSQL or S3-compatible endpoint                     | Used only when the operator configures that database or storage driver. It may receive account data, library content, and files.                                                                                                                                           |
| SMTP server                                              | Sends a password reset email when SMTP is configured and a matching account requests a reset.                                                                                                                                                                              |
| Google or GitHub                                         | OAuth sign-in, linking, token exchange, and identity lookup occur with the matching configured provider.                                                                                                                                                                   |
| Your own instance                                        | The browser, extension, CLI, and MCP server send authorized requests to the origin you choose. MCP clients can send tool results to their own model according to their settings.                                                                                           |

DNS follows the host resolver. Building the app or pulling models and container images contacts the corresponding upstream registries. Those are installation operations. Installed models, notes, uploaded files, snapshots, keyword search, and offline chat can run on the same private network.

Saved sources are treated as untrusted input. The reader renders extracted blocks. The server blocks private fetch destinations by default and the browser restricts application scripts with a per-response policy. [Hardening](hardening.md)
