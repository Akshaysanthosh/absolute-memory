# Changelog

## 0.1.0

First self-hosted release candidate.

- Lite Docker deployment with PGlite, and a Standard Compose deployment with PostgreSQL, pgvector, and a separate worker.
- Local owner setup, invitations, optional SMTP and OAuth, and scoped integration keys.
- Capture of articles, documents, notes, and supported media. Reading and highlighting are available without AI.
- Optional chat, embeddings, and transcription endpoints. Search supports keyword matches and semantic ranking. Chat links back to cited passages.
- Portable library transfers, imports from six common formats, and example saves.
- A versioned HTTP API, CLI, stdio MCP server, and a Chrome extension for a configurable instance.
