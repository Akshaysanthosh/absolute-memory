# Code of Conduct

This project adopts [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) for participation in project spaces and when representing the project.

We expect contributors to treat each other with respect, accept constructive feedback, and look after the health of the community. Harassment, personal attacks, unwanted sexual attention, and sharing private information without permission violate this policy.

Report conduct concerns privately to the repository owner. Include the relevant context and how to contact you for follow-up. Maintainers will handle reports confidentially, review them fairly, and apply the correction, warning, temporary ban, or permanent ban described in the Covenant.
