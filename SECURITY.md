# Security policy

Use **Security → Report a vulnerability** in the GitHub repository to open a private GitHub Security Advisory once the repository is available. Include the affected version, the deployment profile, the expected and observed behavior, and a reproducible example using synthetic data. Keep credentials, private saved content, and active reset links out of the report.

The project maintainer will triage the report and coordinate a fix and disclosure through the advisory. See the [hardening guide](docs/hardening.md) for deployment settings.
